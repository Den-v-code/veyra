# Data Directory

Veyra data is generated or imported evidence, not hand-edited theory.

## Layout

| Path | Role | Tracked |
|---|---|---|
| `raw/` | Source fixtures and immutable captures. | optional |
| `processed/` | Regenerated CSV/JSON certificate tables. | ignored by default |
| `tmp/` | Scratch probes and local experiments. | ignored |

## Rules

1. Raw inputs need provenance: source, date, range, and normalization.
2. Processed files must be regenerated by scripts, usually `make tables`.
3. Temporary files never become citations.
4. Do not store credentials, personal data, or private datasets here.
